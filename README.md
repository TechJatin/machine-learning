## Getting Started

Clone the repository:

```bash
git clone https://github.com/TechJatin/machine-learning.git
cd machine-learning
```

Install common libraries used across the collection (individual scripts may require additional dependencies):

```bash
python -m pip install numpy pandas matplotlib seaborn scikit-learn
```

Run an individual script:

```bash
python kmeans.py
```

Check each script for its specific dataset path and package requirements before running it.

## Repository Structure

Each Python file is an independent learning experiment. Dataset files, when required, must be placed at the path expected by the corresponding script.

## Learning Goals

- Practice common supervised and unsupervised algorithms.
- Explore classification, regression, clustering, recommendation, and NLP.
- Learn data preprocessing, model training, and prediction workflows.

## Note

This is a learning collection. Model behavior and results depend on the data and configuration used by each script. Validate experiments before using them in real-world applications.
